# Critical Logs


<div>

    src="/img/cr-log-1.png"

  />
</div>

**Critical Logs** record high severity system events that require immediate administrative attention. These logs are generated when conditions occur that may impact s**ervice availability, traffic handling, or system stability.**
Critical Logs include, but are not limited to:
- **Backend server health check failures** <br />
Logged when a backend server fails a configured health check and is marked as unhealthy or taken out of service.
- **Backend server failures** <br />
Events where a backend server becomes unavailable or stops responding.
- **System errors** <br />
Critical system level errors that affect core services or application functionality.
- **System warnings requiring attention** <br />
High priority warnings that indicate potential issues which may lead to service disruption if not addressed.
