# User Activity Logs

**User Activity Logs** record actions performed by users within the nBalance system. These logs provide visibility into **administrative and configuration related activities** carried out through the management interface.
They are essential for **auditing, accountability, and troubleshooting**.

---

**What Is Logged** <br />
User Activity Logs include events such as:
-	VIP additions
-	VIP deletions
-	SSL certificate uploads.
-	SSL certificate deletions
-	Policy or security configuration updates
-	GEO-Restrict country added to Allowed list.
-	GEO-Restrict country added to Blocked list.
-	Other administrative actions performed via the UI
