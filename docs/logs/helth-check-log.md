# Health Check Logs

  />
</div>

**Health Check Logs** record the results of **backend server health checks** performed by nBalance to continuously monitor backend availability and responsiveness.
These logs provide visibility into the health check status of backend servers and help administrators verify whether backend services are reachable and functioning correctly.


**What Is Logged** <br />
Health Check Logs include events such as:
- Successful backend health check responses
- Backend health check failures
- Timeout or no response conditions during health checks
- Backend state changes (for example, **UP** or **DOWN**)
