---
title: Delete a Backend Server
sidebar_position: 5
---

1.	Navigate to **TCP Config.**
Click on **TCP Config** from the left navigation menu.
2.	Locate the required **TCP Frontend server** from the list.
3.	Click on **Delete** button corresponding to the backend server you want to delete.
