---
title: Delete a Frontend Server
sidebar_position: 3
---

1.	Navigate to **UDP Config.**
Click on **UDP Config** from the left navigation menu.
2.	Locate the required **UDP frontend server** from the list.
3.	Click on **Delete** button corresponding to the **Frontend server** you want to delete.
