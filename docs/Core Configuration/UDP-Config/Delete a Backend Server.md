---
title: Delete a Backend Server
sidebar_position: 4
---


1.	Navigate to **UDP Config**.
Click on **UDP Config** from the left navigation menu.
2.	Locate the required **UDP Frontend server** from the list.
3.	Click on **Details** button of the **Frontend Server** to which you want to delete a backend **(upstream)** server from. 

<div>
  <img
    src="/img/udp8.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>

4.	Click on **Delete node** button corresponding to the backend server you want to delete.

<div>
  <img
    src="/img/udp9.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>

5.	A confirmation popup message appears to confirm that the backend server has been successfully deleted.

<div>
  <img
    src="/img/udp10.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>
