---
title: Add a Backend Server
sidebar_position: 2
---


1.	Navigate to **UDP Config.**
Click on **UDP Config** from the left navigation menu.

2.	Locate the required **UDP frontend server** from the list.

3.	Click on **Details** button of the Frontend Server to which you want to add a backend **(upstream)** server. 

<div>
  <img
    src="/img/udp4.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>

4.	Enter the backend server **IP address** and **Port number** in the following format.
192.168.0.222:53

<div>
  <img
    src="/img/udp5.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>

5.	 Click **“Add Node”** to add the new backend server.

<div>
  <img
    src="/img/udp6.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>

6.	After a backend node is successfully added to the upstream group, a confirmation dialog is displayed to indicate that the operation completed successfully.

<div>
  <img
    src="/img/udp7.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>
