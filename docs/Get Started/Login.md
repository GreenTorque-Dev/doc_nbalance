##  Steps to Log in to the nBalance Web UI

Follow the steps below to access the nBalance dashboard:

1. Open a web browser and navigate to: 
      **http://[IP_Address]:8000**

2. When the login page is displayed, enter **admin** as the username.

3. Enter **admin** as the password.

4.	Click **Sign** In to authenticate.

5. Upon successful authentication, you will be redirected to the **nBalance dashboard**.
