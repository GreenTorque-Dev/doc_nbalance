### Set Global Max Session Limit

1.	Navigate to **Security**.
Click on **Security** from the left navigation menu.

<div>
  <img
    src="/img/sec1.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>

2.	Locate the **Global Max Session Limit** field.

<div>
  <img
    src="/img/sec2.png"
    alt="Add udp Server"
    style={{  maxWidth: '600px' }}
  />
</div>

3.	In the **Global Max Session Limit** field, enter the maximum number of concurrent sessions allowed.  e.g. **250**
4.	Click **Update** to save the configuration.

Once updated, the system enforces the configured **Global Max Session limit**, allowing only the specified number of active sessions at any given time.
