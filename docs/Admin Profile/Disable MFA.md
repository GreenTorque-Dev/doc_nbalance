# Disable MFA

**Disable Multi Factor Authentication (MFA).**
 
1. Navigate to **Admin Profile** page.
    Click **Admin** in the Top Navigation Bar, then select **Profile** from the drop-down menu.
2. Click on **Disable MFA** button in **MFA Settings** section.

3. MFA is disabled.
