# Change Password     

1.	Navigate to **Admin Profile** page.
Click **Admin** in the Top Navigation Bar, then select **Change Password** from the drop-down menu


<div>
  <img
    src="/img/ch-password.png"
    alt="Add udp Server"
    style={{  maxWidth: '400px' }}
  />
</div>

2.	Enter current password.
3.	Enter new password.
Enter a new password that complies with the password policy.

4.	Confirm the new password.

<div>
  <img
    src="/img/ch-pss2.png"
    alt="Add udp Server"
    style={{  maxWidth: '400px' }}
  />
</div>

5.	Click **Change** to save and update the password
