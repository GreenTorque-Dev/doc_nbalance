# Enable MFA

**Enable Multi Factor Authentication (MFA).**

1. Navigate to **Admin Profile** page.
    Click **Admin** in the Top Navigation Bar, then select **Profile** from the drop-down menu.
2. Install **Google Authenticator** or **Microsoft Authenticator** app in your mobile.

<div>
  <img
    src="/img/mfa-1.png"
    alt="Add udp Server"
    style={{  maxWidth: '400px' }}
  />
</div>

3. Open the app
4. Scan the **QR code** displayed on the **MFA Settings** page.

<div>
  <img
    src="/img/mfa-3.png"
    alt="Add udp Server"
    style={{  maxWidth: '400px' }}
  />
</div>

5. The authenticator app generates a **one time password (OTP)**.
