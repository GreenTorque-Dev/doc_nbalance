# Dashboard 

The **Dashboard** provides a visual summary of **system traffic, alerts, resource utilization, and operational health**, enabling administrators to quickly assess system behavior and performance.

### Accessing the Dashboard

1.	Click on **Dashboard** from the left navigation menu.
2.	The **Dashboard** page is displayed.

### Dashboard Widgets Overview

#### Traffic Rating
Displays the distribution of alerts based on priority levels:
- **High Priority** – Critical alerts
- **Medium Priority** – Moderate alerts
This widget helps administrators quickly understand alert severity and prioritize response actions.

---

#### Protocol Distribution
Shows the distribution of traffic by network protocol handled by the system.
- **Example**: TCP traffic count
This view helps monitor protocol level activity and usage trends.

---

#### Traffic Alerts
Displays high priority alerts over time.
This helps administrators identify traffic patterns, abnormal behavior, and potential security incidents.

---

#### System Information
Displays system resource utilization details, including:
- **Total Memory Installed** – Example: 7.79 GB
- **nBalance Used Memory** – Example: 0.12 GB
This section helps monitor system resource consumption and capacity usage.

---

#### Geo Access
Displays and enforces access control based on the **geographical location** of incoming traffic.
This feature is useful for **allowing or restricting traffic from specific countries** as part of security and compliance policies.
